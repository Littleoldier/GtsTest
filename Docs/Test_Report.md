## 3. RS232/485 串口驱动测试

### 3.1 测试环境

- **虚拟串口对**：COM7 ↔ COM8（com0com）
- **测试工具**：UartAssist V5.0.14
- **驱动配置**：9600-8-N-1

### 3.2 原始流模式

| 测试项 | 结果 |
|--------|------|
| 打开 COM7 | ✅ |
| 打开 COM8 | ✅ |
| COM7 → COM8 发 `Hello\r\n` | ✅ 收到 |
| COM8 → COM7 发 `ddd` | ✅ 收到 |
| 发送 HEX 数据 `48 65 6C 6C 6F` | ✅ 收到 `Hello` |
| 接收区实时显示 | ✅ |
| 自动滚动 | ✅ |

### 3.3 分隔符帧模式

**配置**：分隔符 = `0D 0A`（`\r\n`）

| 发送内容（HEX） | 是否收到 | 说明 |
|-----------------|----------|------|
| `48 65 6C 6C 6F 0D 0A` | ✅ | 以 `\r\n` 结尾，被解析为一帧 |
| `64 64 64 0D 0A` | ✅ | `ddd\r\n` |
| `48 65 6C 6C 6F` | ❌ | 无分隔符，等待更多数据 |
| `41 0D 0A 42 0D 0A` | ✅✅ | 两次触发，两帧 |

### 3.4 定长帧模式

**配置**：帧长 = 8 字节

| 发送内容 | 收到情况 |
|----------|----------|
| 8 字节 | ✅ 1 帧 |
| 16 字节 | ✅ 2 帧 |
| 20 字节 | ✅ 2 帧 + 4 字节缓存 |

### 3.5 头+长度帧模式

**配置**：帧头 = `AA 55`，长度字段偏移 2，长度 2 字节，含 CRC16

| 报文 | 结果 |
|------|------|
| `AA 55 00 08 01 02 03 04 XX XX` | ✅ 收到完整帧 |
| `AA 55 00 08 01 02` | ⏳ 等待剩余 |
| `00 11 AA 55 00 08 ...` | ✅ 丢弃前缀，正确识别 |

### 3.6 自动重连

| 测试步骤 | 结果 |
|----------|------|
| 拔出虚拟串口 | ✅ 检测到断开，日志记录 |
| 3 秒后重新插入 | ✅ 自动重连成功 |

## 6. 视觉服务集成测试

### 6.1 测试环境

- **视觉服务器**：HalconVisionServer (端口 503)
- **测量对象**：20mm 金属圆片
- **算法**：HALCON 亚像素边缘 + `ahuber` 鲁棒圆拟合 + 5 帧中位数

### 6.2 精度测试

| 统计项 | 值 |
|--------|-----|
| **单次采帧** | 5 帧 |
| **有效测量次数** | 29/50 或 50/50（取决于打光） |
| **重复性极差** | 15~20 μm |
| **重复性标准差** | 3~5 μm |
| **单次测量耗时** | 约 300 ms（含 5 帧采集中位数） |

### 6.3 Modbus 数据一致性

| 项目 | 视觉服务端 | GTS 客户端 | 一致性 |
|------|------------|------------|--------|
| 直径 | 20.15 mm | 20.15 mm | ✅ |
| X 坐标 | -27.34 mm | -27.34 mm | ✅ |
| Y 坐标 | -15.76 mm | -15.76 mm | ✅ |
| 缺陷数 | 0 | 0 | ✅ |

**关键修复**：
1. 服务端写入用 `Math.Round` 而非截断
2. 客户端读取时**移除多余的字节交换**
3. 坐标用 `(ushort)(short)value` 存储，读取 `(short)raw / 100.0`
